── what it does

txt

Keeps everything

Text, code, links, images, videos, PDFs, audio and files. Your history stays until you delete it.

key

Keyboard first

Open, search, pick and paste without touching the mouse. Enter pastes straight into the window you came from.

cpu

Idle means idle

The system tells CoBox when something is copied, so it uses almost no CPU while it waits.

pin

Pin what matters

Pinned items stay on top and are never cleaned up, whatever history limit you choose.

pwd

Skips passwords

Copies that password managers mark as private are ignored.

rtl

Speaks your language

Persian, Arabic and Hebrew are shown right to left, the way they're written.

── install

Run this in PowerShell. The same command installs CoBox and updates it later. Your history is never touched.

powershell
